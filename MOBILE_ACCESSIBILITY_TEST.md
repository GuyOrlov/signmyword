# SignMyWord mobile and accessibility test checklist

Use this with real users on at least one iPhone/iOS browser and one Android browser, plus desktop keyboard-only testing.

## Core journey
- [ ] Type a word and submit with the on-screen keyboard.
- [ ] Switch between BSL and ASL.
- [ ] Read the “fingerspelling, not translation” explanation before using results.
- [ ] Open the image maker and change theme and size.
- [ ] Download the PNG successfully.
- [ ] Share through the device share sheet and WhatsApp.
- [ ] Open Classroom sheets and generate each template.
- [ ] Report a hand image/problem using the report link.

## Accessibility
- [ ] Browser zoom at 200% works without horizontal loss of controls or text.
- [ ] Keyboard-only navigation reaches every interactive control in logical order.
- [ ] Focus indicator is always visible.
- [ ] Screen reader announces language buttons, result status and practice progress.
- [ ] Practice mode works with Reveal, Previous, Next and auto-next.
- [ ] Reduced-motion preference does not force smooth scrolling.
- [ ] Text and controls remain usable at narrow mobile widths.

## Recording
For each issue record: device/browser, step, expected result, actual result, screenshot if useful, severity, and whether it blocks the task.
